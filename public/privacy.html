Politica de privacidad

Padelito es una comunidad local para conectar jugadores de padel en Posadas, Misiones.

Datos que usamos

Usamos los datos que el usuario carga en su perfil, como nombre, categoria, posicion, zona habitual y publicaciones creadas. El contacto privado solo se muestra cuando existe una solicitud o invitacion aceptada entre jugadores.

Uso de datos

Los datos se usan para mostrar perfiles, publicaciones, solicitudes, invitaciones, notificaciones internas y actividad relacionada con partidos o eventos.

Servicios externos

La app puede usar Supabase, Cloudflare y Meta para autenticacion, alojamiento, automatizacion de contenido y publicacion social.

Eliminacion

Para pedir eliminacion de datos, segui las instrucciones en eliminacion de datos.
